HexDB 2.3.0 adds tokenization, so card numbers and national IDs are never stored at all; accepts access tokens from your OpenID Connect provider; brings semantic search to SQL and to files; and gives A2A agents streaming, push notifications and a signed agent card. HexDB is now on Docker Hub and Artifact Hub (Helm).

## Added

- **Tokenization.** A schema rule marks a string field `"tokenize": "one_way"` or `"vault"`, and writes replace its value with a token (`tok_<26 characters>_1111`, keeping the last 4 characters as PCI DSS allows) before it reaches the WAL, memory, disk, replicas or backups. Lookups by the real value still work in REST, GraphQL and SQL (joins and subqueries included), and so do unique indexes. One-way tokens can't be reversed by anyone. Vault tokens can be, by users with the new `detokenize` permission (`POST /tessellations/{t}/detokenize`, audited as `token.detokenize`, refused to roles that mask the field). Write answers, transaction results and idempotency records show tokens, never values. Vault entries nothing uses any more are deleted with compaction. A new schema version that tokenizes a field migrates existing documents. The admin UI marks tokens, reveals vault values for users with the permission, and completes `tokenize` in the schema editor. The JavaScript, Python and .NET clients have `detokenize`.
- **OAuth access tokens.** With `oauth.issuer` and `oauth.audience` set, bearer JWTs from that OpenID Connect provider (Entra ID, Auth0, Okta, Keycloak, Google, ...) are accepted on every endpoint. Signatures are checked against the provider's JWKS (RS/PS 256-512, ES256/384, EdDSA; never `none` or HMAC), with `iss`, `aud`, `exp` and `nbf`. The request runs as the existing user whose login or email matches `oauth.user_claim` (default `email`); unknown identities are refused. `GET /.well-known/oauth-protected-resource` (RFC 9728) and the 401 challenge point MCP clients to the provider, and the A2A agent card offers it.
- **Similarity in SQL.** `ORDER BY SIMILARITY(field, 'text' | [vector]) DESC LIMIT k`, with the score selectable as a column, over a vector index.
- **Files by meaning.** A vector index on a files tessellation embeds each file's extracted text, so documents, PDFs and notes are found by what they say.
- **Quantized vector indexes.** `"quantization": "int8"` stores one byte per dimension, a quarter of the memory, and results are rescored exactly from the documents.
- **A2A streaming.** `SendStreamingMessage` (0.3: `message/stream`) answers as Server-Sent Events: the task, a status update per lookup, the answer and the final status.
- **A2A push notifications.** Tasks take webhooks (`CreateTaskPushNotificationConfig` and its Get, List and Delete, or a config on `SendMessage` with `returnImmediately`), and the finished task is POSTed there with the config's token and authentication. Webhooks must be HTTPS to public addresses, checked again when sending; `a2a.push_private_networks` allows private ones.
- **Signed agent card.** The card carries a detached JWS (EdDSA) over its RFC 8785 form, with its key at `/.well-known/jwks.json`, derived from the lattice key.
- **Docker Hub and Helm.** Each release's image is copied to `docker.io/dreaminhex/hexdb`, and a Helm chart is published at `oci://ghcr.io/dreaminhex/charts/hexdb` (listed on Artifact Hub).

## Changed

- `POST /compact` reports `vault_tokens_deleted`.
- The permission catalog has 16 entries (`detokenize`).

HexDB 2.0.1 brings every dependency up to date, hardens a few edges found in another security review, and makes a hex that can't bind its discovery port stop at startup instead of running without peers. Data directories from 2.0 open unchanged. Stored password hashes, MFA codes, sharing link codes and document IDs are checked against reference implementations, so they carry over exactly.

## Security

- **Tessellations named like the admin UI**: a tessellation whose name started with "ui" (such as `uikit` or `uploads`) was treated as part of the admin UI. Its documents were sent without `Cache-Control: no-store` and with the UI's content security policy. Its requests went unlogged, and a replica refused its writes instead of forwarding them to the Overseer. Only `/ui` and paths below it count as the UI now.
- **Audit trail flooding**: every refused request (403) wrote an audit event, so a signed-in user could grow `_audit` as fast as they could send requests. HexDB now records up to 30 refusals per user per minute; the 30th notes that the rest of that minute's aren't recorded. They still appear in the request log.
- **Random keys and nonces** come straight from the operating system's random source.
- Dependency audits (`cargo audit`, `npm audit`) are clean across the server, the admin UI and the drivers.

## Fixes

- A hex that can't bind its discovery port (because another program holds it) now stops at startup with an error naming the port. Before, it started without discovery and never found its peers.

## Dependencies

- **Server**: argon2 0.6, hmac 0.13, sha1 0.11, sha2 0.11, ulid 3, rand 0.10, toml 1.1, tungstenite 0.30, nix 0.31.
- **Admin UI**: Vite 8 (built with Rolldown), Recharts 3, ESLint 10, GraphQL 17. TypeScript stays on 6 until typescript-eslint supports 7.
- **Entity Framework Core provider**: now built on EF Core 9, still for .NET 8 and later. Under EF Core 9, the provider's ULID key generator wasn't being used (EF Core 9 calls a different method to pick it), so this release fixes that.
- **Drivers and CI**: current versions of the .NET test SDK, xunit, the Node types and every GitHub Action.

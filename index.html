HexDB packages

This site hosts the signed APT repository for HexDB. For the database itself, documentation and HexDB Enterprise, go to hexdb.app.

Debian and Ubuntu (amd64, arm64)

curl -fsSL https://dreaminhex.github.io/hexdb/apt/hexdb.gpg | sudo tee /usr/share/keyrings/hexdb.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/hexdb.gpg] https://dreaminhex.github.io/hexdb/apt stable main" | sudo tee /etc/apt/sources.list.d/hexdb.list
sudo apt update && sudo apt install hexdb
sudo systemctl enable --now hexdb

The repository's signing key is also available as ASCII armor.

Other ways to install

Windows and macOS installers, an install script for Linux and macOS, Docker images and a Helm chart are listed in the README. Releases and their notes are on GitHub.

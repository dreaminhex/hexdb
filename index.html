HexDB packages

The signed APT repository for HexDB, the encrypted, replicated document database. Install it on Debian or Ubuntu and get updates with the rest of your system.

Debian and Ubuntu amd64arm64

$ curl -fsSL https://dreaminhex.github.io/hexdb/apt/hexdb.gpg | sudo tee /usr/share/keyrings/hexdb.gpg > /dev/null
$ echo "deb [signed-by=/usr/share/keyrings/hexdb.gpg] https://dreaminhex.github.io/hexdb/apt stable main" | sudo tee /etc/apt/sources.list.d/hexdb.list
$ sudo apt update && sudo apt install hexdb
$ sudo systemctl enable --now hexdb

Packages are signed; the key is also available as ASCII armor. The repository keeps the five newest versions.

Other ways to install

  • Windows and macOS installers, and the Linux and macOS install script: README
  • Docker: ghcr.io/dreaminhex/hexdb, or :<version>-slim for the server only
  • Kubernetes: the Helm chart at oci://ghcr.io/dreaminhex/charts/hexdb
  • Hosted lattices, run for you: HexDB Enterprise

HexDB {{ .Chart.AppVersion }} is starting: {{ .Values.replicas }} hex(es) in the lattice "{{ .Values.latticeName }}".

The admin UI and API:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "hexdb.fullname" . }} 7700:{{ .Values.service.port }}
  open http://localhost:7700/ui/
{{- if not .Values.admin.password }}

The first administrator ({{ .Values.admin.login }}) gets the password in the Secret:
  kubectl -n {{ .Release.Namespace }} get secret {{ include "hexdb.secretName" . }} -o jsonpath='{.data.admin-password}' | base64 -d
{{- if .Values.existingSecret }}
  (Without an "admin-password" key there, HexDB generates one and prints it once in {{ include "hexdb.fullname" . }}-0's log.)
{{- else }}
  (A lattice installed with an earlier chart had its password printed in the log instead; this one applies only to a new lattice.)
{{- end }}
{{- end }}
{{- if not .Values.existingSecret }}

Back up the storage key: the data can't be read without it.
  kubectl -n {{ .Release.Namespace }} get secret {{ include "hexdb.fullname" . }} -o jsonpath='{.data.encryption-key}' | base64 -d
{{- end }}

A forgotten admin password: kubectl -n {{ .Release.Namespace }} exec {{ include "hexdb.fullname" . }}-0 -- hexdb reset-password

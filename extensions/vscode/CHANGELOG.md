# Changelog

## 0.2.1

- **Quarantine.** Administrators of HexDB 2.4 or later see the uploads the malware scan flagged, under each connection: what matched, the engines, who uploaded it and when. Release a false positive (it is stored as a normal file), delete a file for good, or rescan every stored file.
- **A badge on the HexDB icon** counts the quarantined files across your signed-in connections, and a notification tells you when a new one is found. Connections are checked every minute, only while you are signed in.

## 0.1.0

First release: connections by URI (or the public playground), the lattice view, tessellations and documents, SQL and GraphQL with tabbed results, and stored functions.
